This repository contains no API keys, tokens, or credentials.

In a project checkout, run `python -m hydracept init`. Coding agents use stdio MCP (`python -m hydracept mcp serve`) with `.hydracept/secrets.json`. Do not copy workspace keys into Plugins → Configure. Hosted MCP at https://api.hydracept.com/mcp is for clients with no checkout.

Report security issues to support@hydracept.com.
